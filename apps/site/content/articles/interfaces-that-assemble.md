## A small vocabulary

The assistant doesn't write code for each screen. It picks from a small set of
parts, each with a known shape:

1. Text and headings
2. Cards and lists
3. Fields, buttons and toggles
4. Progress, charts and messages

The engine draws them in particles; real elements sit on top, invisible, for
touch and screen readers.

## States you can read across a room

Idle, listening, thinking, speaking and done each get their own movement, so
the panel's state is clear from a glance at the far side of the kitchen.
