## The bands

| Band  | Range      | Often linked to     |
| ----- | ---------- | ------------------- |
| Delta | 0.5–4 Hz   | Deep sleep          |
| Theta | 4–8 Hz     | Drowsiness, drifting |
| Alpha | 8–12 Hz    | Calm, eyes closed   |
| Beta  | 12–30 Hz   | Focus               |
| Gamma | 30–100 Hz  | Binding, attention  |

Each band becomes a mode on a surface. Low bands move the base of a form; high
bands ripple the top. Played together, the form becomes an equaliser you can
walk around.

## Slowed to be watchable

Real brainwaves are far too fast to follow by eye, so the patterns are slowed
by a fixed ratio. The ratios between bands are kept, which is what the eye
reads as harmony.

```
amplitude(t) = Σ a_i · sin(2π · f_i · t / slowdown)
```
